# Research Log

Read this before every run. Append to it after every run.

This is the part that compounds. Three runs in, this file is worth
more than any single research document, because it stops you
rediscovering the same problem every quarter.

## Format

```
## [Date] — [Offer] — [Brief label]
**What happened:** [specific observation]
**Impact on output:** [what it changed, or could have]
**Watch for:** [what to do differently next time]
```

Write entries that would change how the next run goes. "The research
went well" helps nobody.
